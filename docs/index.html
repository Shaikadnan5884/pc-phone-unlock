Unlock your Windows PC with your phone’s fingerprint

No fingerprint sensor on your laptop? When the sign-in screen appears, your phone gets a request. Touch its sensor and Windows signs in. You never type the password.

How it works

Every step is checked for real, and the phone shows it live.

  • 1 Connected to PC
  • 2 Unlock signal received
  • 3 Fingerprint authenticated
  • 4 Response sent to PC
  • 5 PC verified the signature
  • 6 Unlock released, Windows signs in

Pluggable connection

Wi-Fi, phone hotspot, Firebase cloud or Bluetooth. Pair once with a QR code.

Safe by design

The phone signs a one-time challenge. Its key needs your fingerprint and never leaves the phone.

Always a way back

Your normal password and PIN sign-in stay available.

Setup guide

About 10 minutes. Early-stage software, so please try it on a spare PC first.

Before you start

  1. Create a Windows restore point and a second local administrator account that you have tested.
  2. Your Windows account needs a password. A PIN alone does not work. With a Microsoft account, use the Microsoft account password, not the PIN.
  3. Put the phone and PC on the same Wi-Fi or hotspot, and keep both clocks on automatic time.

Install on Windows

  1. Download and run PCUnlock-Setup.exe, then accept the administrator prompt.
  2. Tick the option to allow password sign-in, if asked. Windows blocks password sign-in when “only allow Windows Hello” is on.
  3. Click Install, keep the setup box ticked and click Finish.
  4. Enter your Windows account password. A wrong password is rejected.
  5. In the pairing window choose Wi-Fi, Hotspot, Firebase or Bluetooth and click Generate QR.

Install on Android

  1. Download app-release.apk on the phone and open it. Allow installs from your browser if asked.
  2. Open PC Unlock and allow notifications and the camera.
  3. Tap Scan QR from PC and scan the QR code. The first stage turns green.

Use it

  1. Lock the PC (Start, your user icon, Lock), or restart and wait at the sign-in screen.
  2. The phone shows Unlock your PC? Tap it.
  3. Touch the fingerprint sensor. All six stages turn green and Windows signs in.
Good to know. If you change your Windows password, run C:\pcunlock\setup_tool.exe as administrator again. If the PC’s network address changes, run C:\pcunlock\pair_qr.exe and pair again.

Where your password goes

This is a project that handles a Windows password, so here is what happens to it. The source is public, so you can check each line.

StepWhat happensCode
SetupThe password is checked with Windows on your own PC and stored encrypted (Windows DPAPI, machine scope) in C:\pcunlock\cred.bin. Only SYSTEM and Administrators can open the file.pc/setup_tool.py
UnlockAfter a verified fingerprint the service reads the file and passes it through a local named pipe to the sign-in screen.pc/service.py, pc/pipe_server.py
Windows sign-inThe provider gives the credentials to Windows.provider/PCUnlockProvider/dllmain.cpp
NetworkOnly signed challenges and results travel between phone and PC. The password is never sent to the phone, a website, GitHub or the author.pc/transports.py

Do not just take our word for it: run Wireshark or Process Monitor during setup and unlock and look for outside connections.

Honest limits. Anyone with administrator rights on the same PC can decrypt cred.bin. Wi-Fi traffic uses ws:// (not encrypted) on your local network, and the PC does not yet prove its identity to the phone. Do not use this on shared or high-security machines.

Help and removal

Phone says “Disconnected”

Check that both devices are on the same network, that the firewall rule PCUnlock 8765 exists, and that the service is running (schtasks /Run /TN PCUnlock). If the PC’s address changed, pair again.

The “Unlock with phone” tile does not appear

Check that PCUnlockProvider.dll is in C:\Windows\System32, then restart the PC.

Phone says unlocked but Windows does not sign in

Run setup_tool.exe as administrator with the correct account password (not the PIN), and make sure “only allow Windows Hello sign-in” is off in Settings, Accounts, Sign-in options.

“Request expired” on the phone

The clocks differ. Turn on automatic date and time on both devices.

Uninstall

Settings, Apps, Installed apps, PC Unlock, Uninstall. This removes the sign-in tile, the background task, the firewall rule and the saved password.

Emergency: I cannot sign in

Use the normal password or PIN tile, it is always there. If that fails, hold Shift while clicking Restart, choose Troubleshoot, Startup Settings, Restart, and press 4 for Safe Mode. Then delete C:\Windows\System32\PCUnlockProvider.dll and run unregister.reg from the repository’s pc/tools folder.
